## Key Contributions

- Developed WhatsApp chat import and parsing features supporting `.txt` and `.zip` exports, handling variations in message and date formats.
- Created communication analysis features covering:
  - Message balance
  - Conversation initiation
  - Activity over time
  - Frequently used words and emojis
  - Relationship patterns
- Integrated AI-powered insights and recommendations using **Firebase AI and Gemini**, with Firebase Remote Config for model configuration.
- Integrated Firebase services, including:
  - Firebase Authentication
  - Cloud Firestore
  - Firebase Storage
  - Firebase Analytics
  - Firebase Crashlytics
  - Firebase Remote Config
  - Firebase Cloud Functions
  - Firebase App Check
- Implemented account and subscription flows, including Google and Apple Sign-In, account management, and in-app purchases through RevenueCat.
- Built application state management and navigation using Riverpod, Hooks Riverpod, and GoRouter.
- Developed supporting features such as local notifications, notification history with Sembast, user feedback, account deletion, and usage analytics.
- Implemented privacy-focused data handling. Raw chat data is processed in memory, while structured analysis results are saved.
- Added automated tests for services and view models, covering WhatsApp parsing, subscriptions, authentication, local storage, and analysis results.
